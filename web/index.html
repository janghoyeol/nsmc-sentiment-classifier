영화 리뷰 감성분석

영화 리뷰를 입력하면, 처음부터 설계한 자모 단위 토크나이저 + 소형 GPT(1,186만 파라미터)가 위키백과 한국어 텍스트로 사전학습한 뒤 미세조정되어 긍정/부정을 예측합니다. 외부 사전학습 모델(BERT, GPT 등)은 전혀 쓰지 않았습니다.

예측 결과

    이 모델에 대해

    • 사전학습(언어모델링) → 미세조정(감성분류) 2단계로 직접 학습
    • 같은 구조를 사전학습 없이 학습시킨 비교군 대비 테스트 정확도 82.4% vs 71.2% (NSMC 이진분류, 무작위 추측 기준선 50%) — 사전학습 효과를 수치로 확인
    • 학습/평가 데이터는 Naver Sentiment Movie Corpus(NSMC) 공개 데이터셋 (영화 평점에서 자동 추출된 라벨, train 15만/test 5만)을 그대로 썼습니다. 포트폴리오용 실험 프로젝트이니 참고용으로만 봐주세요.
